# NFFA-EUROPE SEM dataset — downscaled copy

18,577 scanning electron microscope images in 10 classes (one folder per class),
stored as JPEG with a 320 px short side. Used to train the micrograph classifier.

| Class | Images |
|---|---|
| Biological | 953 |
| Fibres | 153 |
| Films Coated Surface | 308 |
| MEMS devices and electrodes | 4,158 |
| Nanowires | 3,656 |
| Particles | 3,412 |
| Patterned surface | 3,310 |
| Porous Sponge | 171 |
| Powder | 895 |
| Tips | 1,561 |
